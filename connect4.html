What is the project about?

A command-line version of the classic Connect Four, built in Python. Designed to support single and multiplayer modes, it applies logical algorithms, data modelling, and declarative programming to deliver an interactive and fair gameplay experience through a clean text-based interface.

Purpose of this project

The challenge was to translate a familiar, visually based board game into a fully functional text-based interface. This required careful consideration of how to visualize the board, manage alternating player turns, and track win conditions purely through console outputs.

Aims & Objectives

  • New two-player game setup
  • Single-player mode against a CPU opponent
  • Turn-by-turn gameplay with clear board updates
  • Automatic win detection and game reset option
